## Instruksi untuk Demo Besok
Aplikasi sudah dalam kondisi **SEMPURNA & SIAP DEMO**.
1.  Nyalakan server Laravel (`php artisan serve`).
2.  Jalankan Flutter (`flutter run` - pastikan mengarah ke `C:\flutter`).
3.  Tunjukkan Kredit Nama Anda di bagian bawah halaman login sebagai bukti autentisitas pengembang.
4.  Demo Fitur: Login -> Dashboard -> KRS per Semester -> Asisten AI -> KTM Digital 3D -> Daftar Mahasiswa (CRUD).
5.  Gunakan `flutter clean` jika logo HD tidak muncul karena masalah cache di device baru.
