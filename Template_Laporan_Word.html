BAB I
PENDAHULUAN

1.1 Deskripsi Tugas

Tugas pekan ini difokuskan pada pembuatan Backend berbasis REST API menggunakan framework Laravel dan integrasinya dengan aplikasi Frontend menggunakan Flutter. Fungsionalitas utama yang diimplementasikan mencakup operasi CRUD (Create, Read, Update, Delete) untuk data mahasiswa, pembuatan dokumentasi API otomatis menggunakan Swagger, serta implementasi fitur upload foto profil.

BAB II
IMPLEMENTASI BACKEND (LARAVEL API)

2.1 Migration & Model

Tabel mahasiswas dirancang untuk menyimpan data akademik mahasiswa secara komprehensif. Kolom yang tersedia meliputi: nim, nama, jurusan, angkatan, email, status, gpa, sks, profilePic, class, dan password.

Model Mahasiswa.php menggunakan trait HasApiTokens untuk mendukung integrasi autentikasi menggunakan Laravel Sanctum.

2.2 Controller (CRUD)

Logika bisnis untuk API dikelola dalam MahasiswaController.php yang terdiri dari beberapa fungsi utama:

  • index(): Mengambil seluruh data mahasiswa dari database.
  • store(): Melakukan validasi input, memproses upload file foto ke storage, dan menyimpan data baru ke database.
  • show($id): Mengambil dan menampilkan detail spesifik dari satu mahasiswa berdasarkan ID.
  • update(Request $request, $id): Memperbarui data mahasiswa yang sudah ada di database.
  • destroy($id): Menghapus data mahasiswa secara permanen.

2.3 Dokumentasi API dengan Swagger

Dokumentasi API telah dibuat secara otomatis menggunakan library L5-Swagger dengan memanfaatkan anotasi OpenApi pada controller. Seluruh resource route untuk /mahasiswa (GET, POST, PUT, DELETE) telah terdaftar dan dapat diakses melalui browser pada path /api/documentation.

BAB III
IMPLEMENTASI FRONTEND (FLUTTER)

3.1 Menampilkan Daftar Mahasiswa (ListView)

Halaman student_list_screen.dart bertugas menampilkan data mahasiswa yang diambil dari API secara real-time. Beberapa komponen utama yang digunakan meliputi:

  • Loading State: Menggunakan CircularProgressIndicator sebagai indikator saat proses fetching data berlangsung.
  • RefreshIndicator: Implementasi fitur "Pull to Refresh" untuk memudahkan pengguna dalam memuat ulang data terbaru dari server.
  • ListView.builder: Digunakan untuk merender daftar mahasiswa secara efisien guna menjaga performa aplikasi.

3.2 Form Tambah & Upload Foto

Halaman mahasiswa_form_screen.dart berfungsi untuk menambahkan data mahasiswa baru. Implementasi pada halaman ini mencakup:

  • Image Picker: Integrasi dengan galeri perangkat untuk memungkinkan pengguna memilih foto profil.
  • Multipart Request: Menggunakan http.MultipartRequest untuk mengirim data teks dan file gambar (foto profil) secara bersamaan ke endpoint Laravel API.

BAB IV
PENGUJIAN (POSTMAN)

4.1 Skenario Pengujian

Seluruh endpoint API telah melalui tahap pengujian menggunakan Postman. Hasil pengujian menunjukkan bahwa API mengembalikan respons JSON sesuai dengan format standar:

  1. GET All Students: Berhasil mengembalikan array objek yang berisi daftar mahasiswa.
  2. POST New Student: Berhasil menyimpan data mahasiswa baru beserta file gambar (upload multipart).
  3. GET By ID: Berhasil menampilkan detail spesifik berdasarkan ID mahasiswa.
  4. PUT Update: Berhasil memperbarui field data mahasiswa seperti nama atau jurusan.
  5. DELETE: Berhasil menghapus data mahasiswa beserta file fotonya dari storage server.
